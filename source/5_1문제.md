## H. 모델 경량화와 양자화

### 69.

대규모 AI/ML 모델에서 경량화가 필요한 이유로 가장 적절한 것은?

① 모델의 모든 출력을 정수로 만들기 위해서이다.
② 학습 데이터를 제거하기 위해서이다.
③ 모델의 파라미터 수와 연산량 증가로 메모리·계산 자원·비용 부담이 커지기 때문이다.
④ 모델의 층 수를 반드시 1개로 줄이기 위해서이다.

### 70.

GPU에 비교적 잘 맞는 모델 경량화 기법의 조합으로 가장 적절한 것은?

① 비정형 pruning만 사용
② 나눗셈 연산만 제거
③ 모든 weight를 문자열로 변환
④ LoRA, QLoRA, 지식 증류, constrained quantization, structured pruning

### 71.

양자화(Quantization)의 핵심 목적은?

① 더 낮은 비트 수 표현을 사용해 연산량과 메모리 사용량을 줄이는 것이다.
② 모델의 파라미터 개수를 반드시 0으로 만드는 것이다.
③ 학습 데이터 크기만 줄이는 것이다.
④ 모델 구조를 완전히 새로 만드는 것이다.

### 72.

양자화 설계에서 특히 중요한 요소로 가장 적절한 것은?

① 입력 문장의 길이만 확인하는 것
② clipping range와 scaling factor를 적절하게 정하는 것
③ 모든 값을 동일한 상수로 바꾸는 것
④ 항상 FP64만 사용하는 것

### 73.

QAT(Quantization-Aware Training)에 대한 설명으로 옳은 것은?

① 학습이 끝난 모델을 추가 학습 없이 바로 변환하는 방식이다.
② pruning 이후에만 사용할 수 있다.
③ forward 과정에서 양자화 효과를 반영하면서 retraining/fine-tuning하는 방식이다.
④ calibration data를 절대 사용하지 않는다.

### 74.

PTQ(Post-Training Quantization)에 대한 설명으로 가장 적절한 것은?

① 모델을 처음부터 다시 학습해야만 한다.
② teacher model이 반드시 필요하다.
③ 모든 weight를 삭제하는 방식이다.
④ 사전학습된 모델에 별도의 retraining 없이 양자화를 적용할 수 있는 방식이다.

### 75.

PTQ 수행 시 calibration data가 사용되는 주된 이유는?

① 양자화 범위와 scale을 정하는 데 필요한 통계 정보를 얻기 위해서이다.
② 파라미터 개수를 늘리기 위해서이다.
③ 모델의 층 수를 추가하기 위해서이다.
④ 학습률을 무조건 0으로 만들기 위해서이다.

### 76.

Weight-only quantization에 대한 설명으로 가장 적절한 것은?

① activation만 양자화하고 weight는 그대로 둔다.
② weight를 낮은 비트로 저장하되 activation은 상대적으로 높은 정밀도를 유지할 수 있다.
③ weight와 activation을 모두 항상 INT8로 만든다.
④ 출력만 양자화한다.

### 77.

Weight-only quantization에서 de-quantization 과정이 필요할 수 있는 이유는?

① 모델의 층을 추가하기 위해서이다.
② activation을 문자열로 바꾸기 위해서이다.
③ 낮은 비트 weight를 연산 장치가 사용하는 형식으로 복원해 계산해야 하는 경우가 있기 때문이다.
④ 지수부를 제거하기 위해서이다.

### 78.

대칭 양자화(symmetric quantization)의 특징으로 가장 적절한 것은?

① 항상 unsigned 정수만 사용한다.
② 최소값과 최대값의 크기가 반드시 다르게 설정된다.
③ zero point가 항상 범위 끝에 위치한다.
④ 0을 중심으로 양수와 음수 범위를 대칭적으로 사용한다.

### 79.

activation의 값 분포가 0을 중심으로 대칭적이지 않을 때 비대칭 양자화(asymmetric quantization)를 고려하는 이유는?

① 데이터의 실제 최소·최대 범위를 더 효율적으로 활용할 수 있기 때문이다.
② 항상 bit 수를 두 배로 만들기 위해서이다.
③ 모델의 파라미터 수를 늘리기 위해서이다.
④ 부동소수점 연산만 허용하기 위해서이다.

① sign 1bit, exponent 8bits, fraction 7bits

Mixed-precision quantization에 대한 설명으로 옳은 것은?

① 모델 전체에 반드시 하나의 동일한 bit-width만 사용한다.
② layer 또는 단위별 특성에 맞게 서로 다른 정밀도의 양자화를 적용할 수 있다.
③ 모든 layer를 FP64로 변환한다.
④ 양자화와 pruning을 동시에 금지한다.

### 85.

모델의 bit 수를 낮추면 항상 GPU 실행 속도가 같은 비율로 빨라지지 않는 이유로 가장 적절한 것은?

## I. 가지치기와 지식 증류

### 86.

가지치기(Pruning)의 기본 개념으로 가장 적절한 것은?

① 모든 weight를 동일한 값으로 만든다.
② 모델의 입력 데이터를 삭제한다.
③ 기존 모델보다 항상 더 큰 모델을 만든다.
④ 중요도가 낮은 weight나 구조를 제거해 모델 크기와 연산량을 줄인다.

### 87.

Magnitude-based pruning이 중요도를 판단할 때 가장 직접적으로 사용하는 기준은?

① weight 값의 절댓값 크기
② 모델의 파일 이름
③ 입력 데이터의 개수만
④ 출력 클래스의 이름

### 88.

Unstructured pruning의 특징으로 옳은 것은?

① 반드시 layer 전체를 제거한다.
② 개별 weight 단위로 불규칙한 sparsity가 만들어질 수 있다.
③ channel 단위로만 제거한다.
④ 모든 GPU에서 즉시 최대 가속을 보장한다.

### 89.

Structured pruning의 장점으로 가장 적절한 것은?

① 개별 weight를 무작위로 제거해 인덱싱 비용을 최대화한다.
② sparsity를 사용하지 않는다.
③ channel이나 layer 같은 규칙적인 단위로 제거해 하드웨어 가속에 활용하기 상대적으로 쉽다.
④ 정확도와 무관하게 항상 100% pruning할 수 있다.

### 90.

Pruning 후 남은 weight의 위치를 저장하기 위한 추가 정보가 필요한 이유는?

① weight 값이 모두 동일하기 때문이다.
② 모델의 입력 크기를 알기 위해서이다.
③ 학습률을 저장하기 위해서이다.
④ 희소하게 남은 값이 원래 행렬의 어느 위치에 있었는지 알아야 하기 때문이다.

### 91.

Pruning에서 CSR(Compressed Sparse Row)과 같은 형식을 사용하는 목적은?

① 희소 행렬의 값과 위치 정보를 압축해 저장하기 위해서이다.
② dense matrix를 더 크게 저장하기 위해서이다.
③ 부동소수점 지수를 저장하기 위해서이다.
④ teacher model을 저장하기 위해서이다.

### 92.

Pruning 비율이 낮거나 하드웨어가 sparsity를 제대로 지원하지 않을 때 발생할 수 있는 문제로 가장 적절한 것은?

① 모델 크기가 반드시 증가한다.
② 인덱싱 오버헤드 때문에 기대한 GPU 가속 효과가 작을 수 있다.
③ pruning이 자동으로 quantization으로 바뀐다.
④ 정확도가 반드시 100%가 된다.

### 93.

Pruning 이후 fine-tuning 또는 retraining을 수행하는 주된 이유는?

① 모델의 파라미터를 원래보다 무조건 늘리기 위해서이다.
② sparsity를 제거하기 위해서이다.
③ 제거된 파라미터로 인해 감소한 성능을 일부 회복하기 위해서이다.
④ 입력 데이터 형식을 변경하기 위해서이다.

### 94.

지식 증류(Knowledge Distillation)의 기본 구조로 가장 적절한 것은?

① 작은 teacher가 큰 student를 학습시킨다.
② 두 모델의 크기는 반드시 같아야 한다.
③ teacher 없이 student를 무작위로 초기화하는 것만 의미한다.
④ 큰 teacher 모델의 지식을 더 작은 student 모델에 전달한다.

### 95.

지식 증류에서 student loss가 의미하는 것으로 가장 적절한 것은?

① ground truth에 대한 student 모델 자체의 학습 손실
② teacher 모델의 파라미터 개수
③ teacher와 student의 모델 크기 차이
④ pruning된 weight의 개수

### 96.

지식 증류에서 distillation loss가 주로 비교하는 것은?

① student의 입력 크기와 teacher의 층 수
② teacher와 student의 예측 분포 또는 soft prediction
③ 두 모델의 파일 크기만
④ 학습 데이터의 개수만

### 97.

PEFT(Parameter Efficient Fine Tuning)의 핵심 아이디어로 가장 적절한 것은?

① 원본 모델을 삭제하고 새 모델을 처음부터 학습한다.
② 항상 전체 weight를 모두 갱신한다.
③ 전체 파라미터 대신 일부 파라미터나 추가 모듈만 학습해 메모리와 학습 비용을 줄인다.
④ 추론할 때만 파라미터 수를 늘린다.

### 98.

Adapter layer를 이용한 파인튜닝에 대한 설명으로 가장 적절한 것은?

① 원본 모델의 모든 weight를 반드시 다시 학습한다.
② 입력 문장 앞에 pseudo-token만 추가하는 방식이다.
③ 원본 weight를 양자화하지 않으면 사용할 수 없다.
④ 원본 모델 내부에 작은 adapter layer를 추가하고 원본 weight는 주로 고정한 채 adapter를 학습한다.

### 99.

LoRA(Low-Rank Adaptation)에 대한 설명으로 옳은 것은?

① 원본 weight는 고정하고 특정 weight matrix에 low-rank update를 추가해 적은 수의 파라미터만 학습한다.
② 모든 layer의 weight를 FP64로 변환한 뒤 전체를 학습한다.
③ teacher model의 soft label만 학습한다.
④ importance가 낮은 weight를 제거하는 pruning 기법이다.

### 100.

QLoRA(Quantized Low-Rank Adaptation)에 대한 설명으로 가장 적절한 것은?

① pruning과 knowledge distillation만 결합한 기법이다.
② 양자화된 기반 모델에 LoRA의 low-rank 학습을 결합해 대규모 모델을 효율적으로 튜닝한다.
③ 원본 모델의 모든 weight를 full fine-tuning한다.
④ prompt tuning에서 pseudo-token만 양자화하는 방식이다.
