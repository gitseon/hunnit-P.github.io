## C. 분포 이동과 Test-Time Adaptation

### 36.

분포 이동(Distribution Shift)이란?

① 모델의 layer 수가 달라지는 현상
② 학습률이 자동으로 증가하는 현상
③ 데이터 개수가 항상 감소하는 현상
④ 학습과 테스트 데이터의 분포가 달라지는 현상

### 37.

분포 이동이 AI 모델에 미칠 수 있는 대표적인 영향은?

① 모델 성능 하락
② 파라미터 수 자동 감소
③ 항상 정확도 향상
④ 학습 데이터 자동 복구

### 38.

분포 이동의 예시로 가장 적절한 것은?

① 학습과 테스트 데이터가 완전히 동일한 경우
② 학습 시 맑고 깨끗한 이미지였지만 실제 테스트 환경에서는 노이즈가 포함된 경우
③ 같은 이미지를 두 번 입력한 경우
④ 모델 파일 이름만 변경한 경우

### 39.

Test-Time Adaptation(TTA)의 기본 개념으로 가장 적절한 것은?

① 테스트 데이터를 모두 학습 label로 사용해 처음부터 재학습한다.
② 테스트 시점에는 모델을 절대 변경하지 않는다.
③ 테스트 데이터를 입력받을 때 모델 일부를 테스트 데이터 통계에 맞게 조정한다.
④ 테스트 데이터의 분포를 학습 데이터와 무조건 동일하게 생성한다.

### 40.

TTA의 주된 목적으로 가장 적절한 것은?

① 학습 데이터의 label을 예측하기 위해서이다.
② 모델의 parameter 수를 최대화하기 위해서이다.
③ 테스트 데이터를 학습 데이터로 영구 저장하기 위해서이다.
④ 테스트 데이터 분포를 파악하여 모델이 새로운 환경에 적응하도록 한다.

### 41.

TTA에 대한 설명으로 옳은 것은?

① 추가 학습 없이도 테스트 시점의 정보를 이용해 모델 일부를 즉시 조정하는 방식이 가능하다.
② 반드시 전체 모델을 처음부터 다시 학습한다.
③ 항상 정답 label이 필요하다.
④ 분포 이동이 없는 경우에만 사용할 수 있다.

도메인 전문가 지식을 AI에 주입하는 방식의 기대 효과로 가장 적절한 것은?

① 전문가 없이도 모든 분야에서 동일한 모델을 그대로 사용할 수 있다.
② 불필요한 시행착오를 줄이고 도메인에 맞는 효율적인 모델을 설계할 수 있다.
③ 모델의 입력 데이터를 모두 제거할 수 있다.
④ 도메인 규칙을 무시할수록 성능이 보장된다.

### 119.

수면단계 자동 채점 사례에서 전문가 지식이 반영된 조합으로 가장 적절한 것은?

① 텍스트 토큰화 + SQL + 이미지 압축
② 센서 exposure 조절 + AHI만 계산
③ 생체신호의 이미지 변환 + 비전 트랜스포머 + epoch 간 맥락 분석
④ 클라우드 업로드 + 수동 label 입력

### 120.

비접촉식 수면 무호흡증 사례에서 도메인 지식이 반영된 핵심 연결은?

① 모든 움직임을 무호흡으로 판단한다.
② 각성 종류를 구분하지 않는다.
③ 영상의 밝기만으로 AHI를 계산한다.
④ 무호흡/저호흡 → 호흡 각성이라는 시간적 관계를 이용해 영상에서 이벤트를 역추적한다.
