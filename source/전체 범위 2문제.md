## D. LLM 학습과 정렬

### 43.

지시 학습(Instruction Tuning)에 대한 설명으로 가장 적절한 것은?

① 사전학습된 언어모델을 (지시문, 응답) 쌍 데이터로 추가 학습시켜 지시를 잘 따르도록 만드는 지도학습 단계이다.
② 강화학습 보상만으로 처음부터 모델을 학습시키는 것이다.
③ 사람의 개입 없이 오직 자기지도학습만으로 완결되는 사전학습 단계이다.
④ 모델 파라미터를 전혀 변경하지 않고 프롬프트만 바꾸는 것이다.

### 44.

지시 학습 데이터셋의 형태로 가장 적절한 것은?

① 레이블이 전혀 없는 순수 텍스트 코퍼스
② (지시문/질문, 바람직한 응답) 쌍으로 구성된 데이터
③ 이미지와 클래스 레이블만으로 구성된 데이터
④ 보상 점수만 기록된 로그 데이터

### 45.

선호 학습(Preference Learning)에서 주로 사용하는 데이터 형태로 가장 적절한 것은?

① 동일 입력에 대한 두 응답 중 사람이 더 선호하는 쪽을 표시한 비교(pairwise comparison) 데이터
② 정답이 하나로 고정된 객관식 문제 데이터
③ 레이블이 전혀 없는 이미지 데이터
④ 오직 숫자형 회귀 타깃만 있는 데이터

### 46.

선호 학습이 궁극적으로 모델에게 기대하는 효과로 가장 적절한 것은?

① 사람이 더 선호하는 방향의 응답을 더 자주 생성하도록 유도하는 것
② 모델의 파라미터 수를 줄이는 것
③ 사전학습 데이터를 완전히 삭제하는 것
④ 토큰화 방식을 바꾸는 것

① 보상모델 학습 → SFT → PPO
② SFT(지도 미세조정) → 보상모델(Reward Model) 학습 → 강화학습(PPO 등)으로 정책 최적화
③ PPO → SFT → 보상모델 학습
④ 강화학습만 단독으로 수행하고 SFT나 보상모델은 사용하지 않는다.

### 48.

RLHF의 두 번째 단계에서 학습하는 보상모델(Reward Model)의 역할로 가장 적절한 것은?

① 사람의 선호를 반영해 응답의 품질(보상)을 점수로 예측한다.
② 원본 텍스트 데이터를 압축해 저장한다.
③ 이미지 분류만 수행한다.
④ 토큰화 규칙을 새로 정의한다.

### 49.

LLM 안전 정렬(safety alignment)의 목적으로 가장 적절한 것은?

① 모델이 인간의 가치와 의도에 부합하도록 유해하거나 편향된 응답을 줄이는 것
② 모델의 파라미터 수를 최대화하는 것
③ 추론 속도만을 최대화하는 것
④ 학습 데이터의 양을 무조건 줄이는 것

### 50.

LLM 안전 정렬 과정에서 활용되는 대표적인 방법으로 가장 적절한 것은?

① RLHF, red-teaming, 거절(refusal) 학습 등을 통해 유해한 출력을 줄인다.
② 모델을 사전학습 이전 상태로 되돌린다.
③ 모든 안전장치를 비활성화하여 자유도를 최대화한다.
④ 토큰화 규칙만 변경한다.

### 51.

Top-K 샘플링에 대한 설명으로 가장 적절한 것은?

① 확률이 높은 상위 K개의 토큰 중에서만 다음 토큰을 샘플링한다.
② 확률이 가장 낮은 K개의 토큰만 샘플링한다.
③ 항상 확률이 가장 높은 토큰 하나만 선택한다(greedy와 동일).
④ K개의 문장을 생성한 뒤 무작위로 하나를 버린다.

### 52.

Top-P(nucleus) 샘플링에 대한 설명으로 가장 적절한 것은?

① 누적확률이 P를 넘는 최소한의 토큰 집합 내에서 다음 토큰을 샘플링한다.
② 고정된 개수 K의 토큰만 항상 고려한다.
③ 확률분포와 무관하게 무작위로 아무 토큰이나 선택한다.
④ 오직 가장 낮은 확률의 토큰만 남기고 나머지를 제거한다.

### 53.

개방형(오픈웨이트) LLM의 특징으로 가장 적절한 것은?

① 모델 가중치와 구조가 공개되어 자유롭게 다운로드, 수정, 온프레미스 배포가 가능하다.
② 반드시 API 호출을 통해서만 사용할 수 있다.
③ 모델 내부 구조를 절대 확인할 수 없다.
④ 어떠한 파인튜닝도 허용되지 않는다.

### 54.

폐쇄형(closed) LLM의 일반적인 특징으로 가장 적절한 것은?

① 가중치는 공개되지 않고 주로 API를 통해서만 접근할 수 있다.
② 누구나 가중치 파일을 자유롭게 내려받아 수정할 수 있다.
③ 항상 무료로 제공된다.
④ 온프레미스 환경에서만 실행 가능하다.

### 55.

파인튜닝(Fine-tuning)에 대한 설명으로 가장 적절한 것은?

① 사전학습된 모델의 가중치를 특정 태스크나 도메인 데이터로 추가 학습해 조정하는 것이다.
② 모델을 처음부터 무작위 초기화하여 새로 학습하는 것이다.
③ 모델 가중치를 전혀 변경하지 않고 입력 데이터만 바꾸는 것이다.
④ 오직 비지도학습으로만 수행해야 한다.

### 56.

파인튜닝이 사전학습(pretraining) 대비 갖는 장점으로 가장 적절한 것은?

① 처음부터 학습하는 것보다 상대적으로 적은 데이터와 자원으로 특정 태스크에 특화시킬 수 있다.
② 항상 더 많은 데이터와 연산 자원을 필요로 한다.
③ 사전학습된 지식을 완전히 무시하고 학습한다.
④ 모델 구조를 매번 새로 설계해야 한다.
