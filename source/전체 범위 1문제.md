④ 입력 데이터의 차원을 무조건 축소하는 것

④ 클러스터링 결과로 자동 생성되는 군집 번호

### 3.

① (f)는 데이터를 만들어내는 참 함수, (\epsilon)은 관측 과정에서 발생하는 측정오차이다
② (f)는 측정오차, (\epsilon)은 모델이 추정한 예측값이다
③ (f)와 (\epsilon)은 모두 모델이 학습을 통해 완전히 제거할 수 있는 값이다
④ (\epsilon)은 항상 0이므로 무시해도 된다

### 4.

측정오차 (\epsilon)에 대한 설명으로 가장 적절한 것은?

① 아무리 좋은 모델을 사용해도 원칙적으로 제거할 수 없는 줄일 수 없는 오차(irreducible error)에 해당한다
② 모델의 파라미터 수를 늘리면 항상 0으로 만들 수 있다
③ (\epsilon)은 모델이 예측한 값 그 자체를 의미한다
④ (\epsilon)이 클수록 모델의 학습이 잘 된 것이다

③ 값이 클수록 모델이 데이터를 전혀 설명하지 못함을 의미한다

### 14.

### 17.

① 회전, 자르기, 뒤집기, 색상 변형 등으로 기존 학습 데이터를 변형하여 데이터의 다양성을 늘리고 일반화 성능을 높이는 기법이다
② 검증 데이터를 훈련 데이터에 몰래 포함시키는 기법이다

### 19.

### 29.

② CNN은 항상 어텐션만 사용하고 합성곱을 사용하지 않는다
③ ViT는 이미지를 절대 패치로 분할하지 않는다
④ CNN과 ViT는 완전히 동일한 구조를 가진 모델이다

### 30.

① 지역성·이동불변성과 같은 inductive bias가 CNN보다 약해 데이터로부터 이러한 패턴을 더 많이 학습해야 하기 때문
② ViT는 합성곱 연산을 사용하므로 데이터가 더 많이 필요하기 때문
③ ViT는 파라미터가 전혀 없기 때문
④ ViT는 이미지를 사용하지 않고 텍스트만 사용하기 때문

## C. 시퀀스·어텐션·언어모델

### 31.

LSTM의 forget gate, input gate, output gate에 대한 설명으로 가장 적절한 것은?

① forget gate는 과거 정보를 얼마나 잊을지, input gate는 새로운 정보를 얼마나 반영할지, output gate는 은닉 상태로 얼마나 내보낼지를 시그모이드로 결정한다
② 세 게이트는 모두 동일한 역할을 하는 중복 구조이다
③ forget gate는 항상 모든 정보를 완전히 삭제한다
④ output gate는 새로운 정보를 cell state에 저장하는 역할을 한다

### 32.

LSTM의 cell state에 대한 설명으로 가장 적절한 것은?

① 게이트들의 조절을 받아 장기적인 정보를 유지·전달하는 통로 역할을 한다
② 매 타임스텝마다 완전히 초기화되어 이전 정보를 전혀 유지하지 않는다
③ cell state는 출력층에서만 사용되고 다음 타임스텝으로 전달되지 않는다
④ cell state를 계산할 때는 ReLU만 사용된다

### 33.

기존 RNN/LSTM 기반 Seq2Seq 구조의 한계로 가장 적절한 것은?

① 입력 시퀀스를 고정 크기의 context vector로 압축하는 병목현상과 긴 시퀀스에서의 장기 의존성 처리 어려움, 순차 처리로 인한 병렬화의 어려움
② 병렬 처리가 지나치게 쉬워 오히려 문제가 된다
③ 입력 시퀀스 길이에 관계없이 항상 완벽한 성능을 보인다
④ 어텐션을 전혀 사용할 수 없는 구조적 한계를 갖는다

### 34.

Transformer가 기존 Seq2Seq 대비 갖는 장점으로 가장 적절한 것은?

① 순환 구조 없이 self-attention만으로 인코더-디코더를 구성해 병렬 학습이 가능하고 장거리 의존성을 더 잘 처리한다
② 반드시 RNN과 결합해야만 동작한다
③ 어텐션 메커니즘을 전혀 사용하지 않는다
④ 입력 시퀀스를 한 번에 하나의 토큰씩만 순차적으로 처리해야 한다

### 35.

셀프-어텐션(Self-Attention)에 대한 설명으로 가장 적절한 것은?

① 하나의 시퀀스 내에서 각 토큰이 자기 자신을 포함한 다른 모든 토큰과의 연관성을 계산해 문맥이 반영된 표현을 만든다
② 서로 다른 두 개의 시퀀스(예: 인코더와 디코더) 사이에서만 정의될 수 있다
③ Query, Key, Value를 서로 다른 시퀀스에서 각각 가져와야 한다
④ 합성곱 연산을 대체할 수 없는 개념이다

### 36.

셀프-어텐션에서 Query, Key, Value가 만들어지는 방식으로 가장 적절한 것은?

① 동일한 입력 시퀀스에 서로 다른 가중치 행렬을 곱하여 각각 생성한다
② Query는 입력에서, Key와 Value는 반드시 별도의 외부 데이터베이스에서 가져온다
③ Query, Key, Value는 항상 동일한 값으로 고정되어 있다
④ Value만 존재하고 Query와 Key는 사용되지 않는다

### 37.

어텐션 메커니즘의 계산 과정으로 가장 적절한 것은?

① (\text{softmax}(QK^T/\sqrt{d_k})V)와 같이 Query와 Key의 유사도로 가중치를 구하고 이를 Value에 곱해 가중합을 계산한다
② Key와 Value만 곱하고 Query는 사용하지 않는다
③ Query와 Value를 직접 더하여 최종 출력을 만든다
④ 가중치를 항상 균등하게(1/n) 고정하여 Value를 평균낸다

### 38.

어텐션 스코어 계산에서 (\sqrt{d_k})로 나누어주는(스케일링하는) 이유로 가장 적절한 것은?

① 내적 값이 커질수록 softmax의 기울기가 지나치게 작아지는 것을 방지하기 위해
② Key의 차원 수를 늘리기 위해
③ Value의 값을 항상 음수로 만들기 위해
④ Query를 0으로 만들기 위해

### 39.

멀티-헤드 어텐션(Multi-Head Attention)에 대한 설명으로 가장 적절한 것은?

① 여러 개의 서로 다른 표현 부분공간에서 어텐션을 병렬로 수행한 뒤 그 결과를 이어붙이고 선형변환하여 다양한 관계를 동시에 포착한다
② 하나의 head만으로 모든 관계를 표현하기 위해 고안된 구조이다
③ 여러 head의 결과는 서로 더해지지 않고 항상 하나만 선택되어 사용된다
④ 멀티-헤드 어텐션은 셀프-어텐션과 전혀 관련이 없는 별개의 개념이다

### 40.

멀티-헤드 어텐션을 사용하는 주된 이유로 가장 적절한 것은?

① 서로 다른 head가 서로 다른 종류의 관계(예: 구문적 관계, 의미적 관계 등)를 각각 포착할 수 있도록 하기 위해
② 연산량을 줄이기 위해 head 수를 최대한 늘리는 것이 목표이기 때문
③ head 수가 많아질수록 모델의 파라미터가 항상 줄어들기 때문
④ head 사이에 정보를 공유하지 않는 것이 필수 조건이기 때문

### 41.

언어모델(Language Model)의 기본적인 학습 목적으로 가장 적절한 것은?

① 이전까지의 토큰(문맥)이 주어졌을 때 다음 토큰의 확률분포 (P(w_t\mid w_1,\dots,w_{t-1}))를 예측하도록 학습한다
② 레이블이 부착된 이미지를 분류하는 것을 목적으로 한다
③ 입력 문장을 클러스터링하여 군집으로 나누는 것을 목적으로 한다
④ 문장의 각 단어를 무작위로 삭제하는 것을 목적으로 한다

### 42.

대규모 텍스트로 언어모델을 사전학습할 때의 특징으로 가장 적절한 것은?

① 별도의 사람이 직접 부여한 레이블 없이 텍스트 자체의 다음 토큰 예측을 지도신호로 사용하는 자기지도학습(self-supervised learning) 방식이다
② 반드시 사람이 모든 문장에 대해 정답 레이블을 일일이 부여해야 한다
③ 이미지 데이터만을 사용하여 학습한다
④ 학습 데이터의 양이 적을수록 성능이 더 좋아진다

## D. LLM 학습과 정렬

### 43.

지시 학습(Instruction Tuning)에 대한 설명으로 가장 적절한 것은?

① (지시문, 응답) 쌍으로 이루어진 데이터로 사전학습된 언어모델을 추가로 지도학습시켜 사용자의 지시를 더 잘 따르도록 만드는 과정이다
② 모델의 가중치를 전혀 변경하지 않고 프롬프트만 바꾸는 과정이다
③ 레이블이 전혀 없는 데이터로 비지도 클러스터링을 수행하는 과정이다
④ 이미지 데이터만을 사용하는 학습 방식이다

### 44.

지시 학습을 거친 모델이 지시 학습 이전과 비교해 갖는 차이로 가장 적절한 것은?

① 동일한 사전학습 지식을 바탕으로 하되, 질문이나 명령 형태의 입력에 더 적절하고 지시를 따르는 형태로 응답하는 경향이 강해진다
② 사전학습에서 학습한 지식을 모두 잃어버린다
③ 반드시 파라미터 수가 두 배로 증가한다
④ 더 이상 자연어를 이해하지 못하게 된다

### 45.

선호 학습(Preference Learning)에 대한 설명으로 가장 적절한 것은?

① 동일한 입력에 대한 두 개 이상의 응답 중 사람이 더 선호하는 응답과 그렇지 않은 응답을 비교한 데이터를 이용해 모델이 더 선호되는 출력을 내도록 학습하는 방식이다
② 레이블이 전혀 없는 원시 텍스트만으로 다음 토큰을 예측하는 사전학습 방식이다
③ 이미지와 텍스트 쌍을 대조학습하는 방식이다
④ 합성곱 필터의 개수를 조정하는 방식이다

### 46.

선호 학습에 사용되는 데이터의 형태로 가장 적절한 것은?

① 동일 질의에 대한 응답 쌍과 그중 어느 쪽이 더 선호되는지를 나타내는 비교(랭킹) 레이블
② 오직 정답이 하나뿐인 객관식 문제 데이터
③ 레이블이 전혀 없는 이미지 데이터
④ 음성 파형 데이터만

### 47. ★

RLHF(Reinforcement Learning from Human Feedback)의 일반적인 학습 절차로 가장 적절한 것은?

① 지도 미세조정(SFT) → 사람 선호 비교 데이터로 보상모델(Reward Model) 학습 → 보상모델을 이용한 강화학습(PPO 등)으로 정책 최적화
② 강화학습 → 사전학습 → 지도 미세조정 순으로 진행되며 보상모델은 사용하지 않는다
③ 보상모델 학습만으로 전체 과정이 끝나며 강화학습 단계는 존재하지 않는다
④ 이미지 데이터에 대해서만 적용 가능한 절차이다

### 48.

RLHF에서 보상모델(Reward Model)의 역할로 가장 적절한 것은?

① 사람의 선호 비교 데이터를 학습해 임의의 응답에 대해 사람이 선호할 만한 정도를 점수로 예측한다
② 이미지를 텍스트로 변환하는 역할을 한다
③ 학습 데이터의 개수를 자동으로 늘리는 역할을 한다
④ 합성곱 필터의 파라미터를 초기화하는 역할을 한다

### 49.

LLM의 안전 정렬(Safety Alignment)이 목표로 하는 것으로 가장 적절한 것은?

① 유해하거나 편향되거나 사실이 아닌 출력을 줄이고 모델의 행동을 인간의 가치와 의도에 부합하도록 만드는 것
② 모델의 파라미터 수를 최대한 늘리는 것
③ 학습 속도를 최대한 빠르게 만드는 것
④ 이미지 해상도를 최대한 높이는 것

### 50.

LLM 안전 정렬을 위해 활용되는 방법으로 가장 적절한 것은?

① RLHF를 통한 선호 기반 학습, red-teaming을 통한 취약점 탐색, 부적절한 요청에 대한 거절(refusal) 학습 등
② 모델을 전혀 학습시키지 않고 그대로 배포하는 것
③ 학습 데이터의 다양성을 의도적으로 줄이는 것
④ 모델의 모든 안전장치를 비활성화하는 것

### 51.

디코딩 시 Top-K 샘플링에 대한 설명으로 가장 적절한 것은?

① 다음 토큰 확률분포에서 확률이 높은 상위 K개의 토큰만 남기고 그 안에서 샘플링하는 방식
② 확률이 가장 낮은 토큰을 항상 선택하는 방식
③ 모든 토큰을 동일한 확률로 샘플링하는 방식
④ 가장 확률이 높은 토큰 단 하나만 항상 결정론적으로 선택하는 방식(그리디 디코딩)

### 52.

Top-P(nucleus) 샘플링에 대한 설명으로 가장 적절한 것은?

① 확률이 높은 토큰부터 누적하여 누적확률이 P를 넘는 최소한의 토큰 집합 내에서만 샘플링하는 방식
② 고정된 개수 K개의 토큰만 항상 사용하는 방식으로 Top-K와 완전히 동일하다
③ 확률분포와 무관하게 무작위로 아무 토큰이나 선택하는 방식
④ 디코딩 과정에서 확률이 가장 낮은 토큰들만 모아서 샘플링하는 방식

### 53.

개방형(오픈웨이트) LLM과 폐쇄형 LLM을 비교한 설명으로 가장 적절한 것은?

① 개방형은 모델 가중치와 구조를 공개하여 자유롭게 다운로드·수정·온프레미스 배포가 가능하고, 폐쇄형은 API를 통해서만 접근 가능하며 가중치가 공개되지 않는다
② 개방형과 폐쇄형은 접근 방식에 차이가 전혀 없다
③ 폐쇄형 LLM은 반드시 무료로 가중치를 다운로드할 수 있다
④ 개방형 LLM은 절대로 파인튜닝할 수 없다

### 54.

폐쇄형(closed) LLM 서비스를 사용할 때의 일반적인 특징으로 가장 적절한 것은?

① 모델 가중치를 직접 다루지 않고 API 호출을 통해 결과를 받으며, 제공자가 관리하는 최신 모델을 손쉽게 사용할 수 있는 대신 내부 구조에 대한 투명성과 커스터마이징에는 제약이 있다
② 모델 내부 가중치를 사용자가 직접 자유롭게 수정할 수 있다
③ 서버를 반드시 사용자가 직접 구축하고 운영해야 한다
④ 인터넷 연결 없이도 항상 로컬에서 실행된다

### 55.

파인튜닝(Fine-tuning)에 대한 설명으로 가장 적절한 것은?

① 사전학습된 모델의 가중치를 특정 태스크나 도메인의 데이터로 추가 학습하여 조정하는 과정으로, 처음부터 학습하는 것보다 적은 데이터와 자원으로 특화된 성능을 얻을 수 있다
② 모델의 가중치를 전혀 변경하지 않고 입력 프롬프트만 바꾸는 과정이다
③ 사전학습 자체를 의미하며 추가 데이터가 전혀 필요 없다
④ 레이블이 없는 데이터로 클러스터링을 수행하는 과정이다

### 56.

파인튜닝과 지시 학습(Instruction Tuning)의 관계에 대한 설명으로 가장 적절한 것은?

① 지시 학습은 파인튜닝의 한 형태로, (지시문, 응답) 데이터를 이용해 모델이 지시를 잘 따르도록 추가 학습하는 것이다
② 파인튜닝과 지시 학습은 서로 완전히 무관한 별개의 개념이다
③ 지시 학습은 파인튜닝보다 상위 개념으로, 파인튜닝을 포함하지 않는다
④ 지시 학습은 모델 가중치를 절대 변경하지 않는다

## E. 멀티모달·생성 모델

### 57.

CLIP(Contrastive Language-Image Pretraining)의 학습 방식에 대한 설명으로 가장 적절한 것은?

① 이미지 인코더와 텍스트 인코더로 각각 임베딩을 만든 뒤 대규모 (이미지, 텍스트) 쌍 데이터로 대조학습을 수행하여 짝이 맞는 쌍의 임베딩은 가깝게, 그렇지 않은 쌍은 멀어지도록 학습한다
② 오직 이미지 데이터만으로 학습하며 텍스트는 전혀 사용하지 않는다
③ 레이블이 있는 소규모 분류 데이터셋만으로 지도학습된다
④ 이미지와 텍스트를 하나의 동일한 인코더로만 처리한다

### 58.

CLIP의 이미지 인코더와 텍스트 인코더에 대한 설명으로 가장 적절한 것은?

① 두 인코더는 서로 다른 modality(이미지, 텍스트)의 입력을 같은 임베딩 공간의 벡터로 변환하도록 함께 학습된다
② 텍스트 인코더는 학습에 전혀 관여하지 않고 고정되어 있다
③ 이미지 인코더는 오직 흑백 이미지만 처리할 수 있다
④ 두 인코더의 출력은 서로 다른 차원의 공간에 존재해야 한다

### 59.

CLIP을 이용한 Zero-shot 이미지 분류 과정으로 가장 적절한 것은?

① 클래스 이름들을 'a photo of a {class}'와 같은 텍스트 프롬프트로 만들어 텍스트 인코더에 입력하고, 입력 이미지 임베딩과 각 클래스 텍스트 임베딩 간의 코사인 유사도가 가장 큰 클래스를 예측 결과로 선택한다
② 해당 클래스 데이터로 반드시 추가 지도학습을 수행한 뒤에만 분류할 수 있다

② 반드시 새로운 클래스마다 모델 전체를 처음부터 재학습해야 한다

### 61.

Diffusion 모델의 이미지 생성 원리로 가장 적절한 것은?

② 원본 이미지를 한 번의 연산으로 완전히 다른 이미지로 변환하는 결정론적 함수이다
③ 노이즈를 전혀 사용하지 않고 픽셀을 직접 복사하는 방식이다
④ 이미지가 아닌 텍스트만 생성할 수 있는 모델이다

### 62.

Diffusion 모델의 reverse process(역과정)에 대한 설명으로 가장 적절한 것은?

① 노이즈가 섞인 이미지에서 각 단계마다 모델이 예측한 노이즈를 제거해 점진적으로 원본에 가까운 깨끗한 이미지를 복원해 나가는 과정이다
② 원본 이미지에 노이즈를 추가해 완전한 노이즈로 만드는 과정이다
③ 이미지를 텍스트로 변환하는 과정이다
④ 학습이 전혀 필요 없는 고정된 규칙 기반 과정이다

### 63.

온디바이스 VLM(sVLM)의 목적으로 가장 적절한 것은?

② 클라우드 서버에서만 실행 가능하도록 모델 크기를 최대한 키우는 것
③ 이미지 입력을 아예 사용하지 못하도록 제한하는 것
④ 인터넷 연결이 필수적으로 항상 필요하도록 만드는 것

### 64.

① 모델 파라미터의 정밀도 비트 수를 낮추는 양자화(Quantization) 등을 통해 모델 크기와 메모리 사용량을 줄이는 방법

③ 이미지 인코더를 제거하고 언어모델만 남기는 방법
④ 학습 데이터를 전혀 사용하지 않고 무작위 초기화된 가중치만 사용하는 방법
